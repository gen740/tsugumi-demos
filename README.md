# Tsugumi demos

Demo projects for [Tsugumi](https://github.com/gen740/Tsugumi), in English (`en/`) and Japanese (`ja/`). Each directory under `en/` and `ja/` is a complete Tsugumi project: open it in the Mac app or `tsugumi web`. `en/index.json` and `ja/index.json` list the demos with their titles and descriptions, and `reference/` holds reference material the demos share.

The English and Japanese copies match: change both.

The demos use only Tsugumi's public contract: the project files, the Card ABI and the [tsugumi-kit](https://github.com/gen740/tsugumi-kit) SDKs, pinned in each project's `tsugumi.lock`. That makes them a test suite for the contract as well as examples.

This repository was split from `demos/` in the Tsugumi repository on 2026-11-25, with its history.
